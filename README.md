# Sort Numbers in Descending Order

## Explanation

This Python program accepts a list of numbers and arranges them in descending order, from the largest number to the smallest number.

## Problem Statement

Write a Python program to input a list of numbers and sort them in descending order.

## Features

* Accepts multiple numbers.
* Stores numbers in a list.
* Sorts numbers from largest to smallest.
* Displays the sorted list.

## How It Works

1. Read numbers from the user.
2. Store them in a list.
3. Use the `sort()` method with `reverse=True`.
4. Display the list in descending order.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `split()`
* `map()`
* `sort()`

## Program Flow

Input → Create List → Sort in Descending Order → Display Result

## Sample Input

```text
10 50 20 40 30
```

## Sample Output

```text
Descending order: [50, 40, 30, 20, 10]
```

## Time Complexity

O(n log n)

## Space Complexity

O(n)
